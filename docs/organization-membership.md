# Organization membership

Repositories in the [stac-utils](https://github.com/stac-utils/) Github organization are shared resources, used across our community and software ecosystem.
Because of that, no single entity has control over all of **stac-utils**; this includes the [STAC Project Steering Committee](https://github.com/radiantearth/stac-psc/), whose remit only extends to the STAC specifications and their extensions.
The **stac-utils** organization therefore has a very small number of owners who have organization-level permissions.
Permissions are managed at the repository level by individual repository maintainers via outside collaborators.

See https://github.com/orgs/stac-utils/people for a list of public members of the organization.
